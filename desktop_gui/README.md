# 🖥️ Desktop GUI Module (`desktop_gui/`)

The **desktop_gui** contains Tkinter-based desktop management tools for mall operations, data auditing, vector inspection, and scraper management.

---

## 📁 Files

- [`main.py`](./main.py) — Desktop GUI launcher containing the main Notebook interface.
- [`shopper_assistant.py`](./shopper_assistant.py) — Interactive shopper AI conversation interface.
- [`admin_dashboard.py`](./admin_dashboard.py) — Operational dashboard showing system health, active services, and live audit flags.
- [`scraper_pipeline.py`](./scraper_pipeline.py) — Web scraper control panel for scheduling and manual triggers.
- [`vector_workbench.py`](./vector_workbench.py) — ChromaDB hybrid search & dense vector inspector tool.
- [`catalog_manager.py`](./catalog_manager.py) — Store product catalog management table.

---

## 🚀 How to Run

```bash
python desktop_gui/main.py
```
