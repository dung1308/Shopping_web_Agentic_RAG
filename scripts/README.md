# 🔧 Helper Scripts (`scripts/`)

Utility scripts for setting up local models and verifying environment configurations.

---

## 📁 Scripts

- [`check_llm_connection.py`](./check_llm_connection.py) — Tests connectivity to Ollama / local LLM endpoints and validates model response generation.
- [`download_model.py`](./download_model.py) — Utility script to download HuggingFace embedding or LLM models locally.

---

## 🚀 Usage

```bash
python scripts/check_llm_connection.py
python scripts/download_model.py
```
